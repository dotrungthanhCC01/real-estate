
# 🏢 Real Estate System (Smart Estate)

Hệ sinh thái nền tảng Quản lý & Giao dịch Bất động sản Toàn diện bao gồm Web, Mobile App và Backend Service.

---

## 📂 Cấu Trúc Dự Án (Project Structure)

```text
ltwnc/
├── BE/                  # Backend API Services
├── EstateApp/           # Ứng dụng di động (React Native - iOS & Android)
└── smart-estate-web/    # Ứng dụng Web người dùng & Quản trị (React, Vite, Tailwind CSS)
```

---

## 📌 Các Thành Phần (Modules)

### 1. [BE (Backend Service)](./BE/README.md)
- Dịch vụ máy chủ cung cấp REST API, xử lý nghiệp vụ, xác thực và lưu trữ dữ liệu cho Web và Mobile App.

### 2. [EstateApp (Mobile App)](./EstateApp/README.md)
- Ứng dụng di động xây dựng bằng **React Native**.
- Hỗ trợ trải nghiệm tìm kiếm, định vị, đặt lịch và quản lý bất động sản trên thiết bị Android & iOS.

### 3. [smart-estate-web (Web Frontend)](./smart-estate-web/README.md)
- Nền tảng web hiện đại xây dựng bằng **React 19, TypeScript, Vite, Tailwind CSS, Shadcn UI**.
- Hỗ trợ đầy đủ chức năng: Cổng thông tin tìm kiếm, bản đồ Leaflet, đặt lịch xem nhà, quản lý tin đăng, Blog tin tức, trang Quản trị (Admin) & Chủ nhà (Landlord).
