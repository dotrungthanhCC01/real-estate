# ⚙️ Real Estate Backend Service (BE)

Backend API và dịch vụ xử lý dữ liệu cho hệ thống Real Estate.

## 📌 Tổng quan
Thư mục chứa mã nguồn backend phục vụ cho hệ thống Smart Estate / Real Estate:
- Quản lý người dùng, phân quyền (Admin, Landlord, User/Buyer)
- Quản lý danh sách bất động sản, bài đăng, hình ảnh
- API tìm kiếm, lọc, bản đồ và hỗ trợ đặt lịch hẹn
- WebSocket / Realtime notification & chat
